# 关于本站

这里放两样东西：软件的使用说明，和零散的技术观点。前者求准，会一直改；后者求诚，写完就放着。

## 怎么组织的

“软件手册”里是一篇篇可以照着做的文档，每篇只解决一个具体问题。“技术博客”里是一时一地的想法，不保证以后还同意。两者共用同一套页面布局：左边是目录，中间是一栏正文，左下角随时能反馈。

## 关于图片

文章里的插图都是自己画的示意，不引用别人的截图。图片和正文一起存，换地方时不会丢。

## 怎么联系

有错别字、跑不通的步骤，或者不同意见，都可以点左下角的“意见反馈”，写清楚页面和现象就行。
