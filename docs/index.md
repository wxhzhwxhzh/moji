# 使用引导

??? note "如何开始写第一篇文档"

    在左侧目录里挑一个分类，点页面右上角的“新建”就能写正文。内容先写进草稿，第二次编辑时会自动保存；标题就是文件名，写得具体一点，将来才好找。

    [阅读全文](docs/getting-started.md)

??? note "文章里怎么放图片和截图"

    把图片直接拖进正文，或者从剪贴板粘贴。图片会按正文栏的宽度自动缩小，手机上看也不会出现横向滚动条；截图建议先裁掉无关的边框再上传。

    [阅读全文](docs/images-and-embeds.md)

??? note "一篇长文档怎么分小节"

    用二级标题把内容拆成几个小节，读者可以挑着看。每个小节标题都会自动生成锚点，分享的时候可以直接指到某一段。

??? note "文档、博客和笔记怎么分工"

    需要长期维护的操作说明放文档，一次性的观点和零散记录放博客，还没想清楚的东西先放在笔记里；稿子成熟了再搬出去。

??? note "怎么写带代码的教程"

    用三个反引号把代码围起来，并在第一行写上语言名字。代码块会保持等宽字体、保留缩进，太长的行可以横向滚动，不会撑破页面。

    [看写法](docs/images-and-embeds.md)

??? note "常用的快捷键有哪些"

    搜索是 Cmd（Windows 上是 Ctrl）加 K，新建是 N，保存不用管，输入停顿后会自己存。其余快捷键都列在命令面板里，用 Cmd + / 打开。

??? note "换一台设备怎么接着写"

    在另一台设备上登录同一个账号即可，内容会同步过来。没有网络时照常写，联上网以后改动会自动合并，冲突的部分会留两份让你挑。

??? note "这个文档站是怎么搭起来的"

    整站是构建时生成的静态文件：内容写成纯文本，构建脚本套上同一个页面外壳，输出一组 HTML，放到任何静态托管上都能跑。

    [阅读全文](blog/building-docs-site.md)

??? note "怎么备份自己的内容"

    正文都是纯文本的源文件，每周打一次包下载下来，就等于有一份完整的备份；需要时把文件夹放回原处就能恢复。

??? note "发现问题去哪儿说"

    点左下角的“意见反馈”，写清楚是哪个页面、点了什么、看到了什么。附上复现步骤比截图更有用。

??? note "想自己加一篇博客怎么办"

    文章都是普通文本文件：在 `docs/blog/` 里新建一个文件，开头写标题、日期和分类，下面写正文，生成一次站点，首页和博客列表就会自动多出这一篇。

    [照着做](docs/publishing-a-post.md)
