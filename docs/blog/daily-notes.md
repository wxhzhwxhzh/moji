# 每天写一百字

![书桌、摊开的笔记本和一支笔的扁平插图](../images/handbook.svg)

<!--META-->

我试过很多次“每天写点什么”，只有降到一百字才真的坚持下来。一百字大概是一段话，写得完，也懒得找借口。

## 先写下来，别先想结构

当天遇到的一个坑、一句解释、一张截图，都值得记。结构是后来才需要的：等同一个主题攒到第五段，它自己就会冒出一个小标题。

## 每周收一次

周末花二十分钟翻一遍这周的笔记，把同类的挑出来，能合成一篇的就合成，剩下的留在草稿里。写文档和写博客的材料，基本都是这么来的。

> 记录的价值不在写的时候，而在半年后你想不起来某件事、却能搜到它的那一刻。
