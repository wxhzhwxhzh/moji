# 五分钟上手：写下第一篇文档

![书桌、摊开的笔记本和一支笔的扁平插图](../images/handbook.svg)

<!--META-->

这篇文档只做一件事：把“新建一篇能看的文档”这件事从头走一遍。走完以后你就有了一套自己的结构，接下来往里填内容就行。

## 新建一篇文档

登录之后，左侧目录里选一个分类，点页面右上角的“新建”。标题就是文件名，写得具体一点，比如“在 Linux 上安装开发环境”，而不是“笔记 1”。具体的好处是三个月以后你还能搜到它。

正文用 Markdown 写：空一行就是新段落，行首加 `#` 是标题，两个星号包起来是加粗。写作时不用管排版，样式由站点统一给。

## 用标题给文章分段

一篇文档里只用两级标题就够了，再多读者会迷路：

- 一级标题只留给文章名，一篇文章一个；
- 二级标题把正文切成一件事一个小节，按操作顺序排；
- 三级标题只在某一步骤里还要细分的时候才用。

![编辑界面的插图：左边写正文，右边看效果](../images/editor.svg)

*编辑时左边写正文，右边的预览会随时更新，插图会按正文栏的宽度自动缩小。*

## 一个可以照着抄的例子

下面的结构对大多数“怎么装、怎么配”的文档都适用：

```
# 在 Linux 上安装开发环境

## 1. 准备工作

- 一块至少 20GB 的空闲磁盘
- 能联网的账号

## 2. 安装包管理器

按照官网的说明执行一行命令即可。

## 3. 检查是否装好

运行 `dev --version`，能看到版本号就成功了。
```

> 把“写给三个月后的自己看”当作标准：那时你已经忘了当时为什么这么做，所以原因比步骤更重要。

## 保存与发布

停下来的时候内容已经自动保存了，不需要另存。要给别人看就点文章右上角的“分享”，拿到的链接只读；想放到博客里，复制正文过去再补一段开头即可。
