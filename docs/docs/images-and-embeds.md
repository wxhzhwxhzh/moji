# 在文章里放图片、截图和代码

![编辑界面的插图：左边写正文，右边看效果](../images/editor.svg)

<!--META-->

一篇讲操作的文档，一半的信息在文字里，另一半在图上。这一页说清楚图片怎么进来、怎么在手机上也好看。

## 拖进来就行

新建一段空行，把图片文件拖到编辑区，或者直接粘贴一张截图。上传完成后正文里会出现一行图片语法，光标不动，接着写下一段就好。

![书桌、笔记本和笔的插图](../images/handbook.svg)

*插入的图片默认按正文栏宽度显示：桌面是一整栏，手机上是屏幕宽度，两边都不会溢出。*

## 图片的宽度

正文栏是固定宽度，图片再大也会缩到栏内，所以原图大一点没关系。真正要注意的是高度：一屏放不下的长截图，读者很难对齐上下两段，建议拆成几张，或者用文字把关键行说清楚。

- 截图前先裁掉工具栏和无关的边框；
- 一张图只说明一件事，需要对比就做成两张；
- 给图片写一句说明，读屏软件和搜索都靠它。

## 代码块

三个反引号开头，第一行写上语言名字，代码就会用等宽字体排好。太长的行不会换行，而是让这一块自己横向滚动，页面不会跟着动。

```bash
# 检查装好了没有
dev --version

# 看一下配置文件在哪
dev config path
```

行内的一小段命令用单个反引号包起来，比如 `dev --version`，它会带一层浅底，和正文区分开。

## 引用和提示

> 容易出错的地方用引用块单独写一行：它的左边有一条竖线，读者扫一眼就能看到。
